# Aerospace Manufacturing AI

## Goal
Build an aerospace manufacturing assistant that can analyze STEP/STP files and help reduce manual review time for programmers, estimators, and manufacturing engineers.

## First MVP
The first version will:
- Upload STEP/STP files
- Store uploaded files
- Extract basic geometry metadata
- Display part information in a dashboard
- Generate a clean part report

## Future Features
- Feature extraction
- Manufacturability warnings
- Machine recommendations
- Cost estimation
- Similar past job search
- AI manufacturing assistant
- Mastercam/CAM workflow support

## Tech Stack
- Python FastAPI backend
- React frontend
- PostgreSQL database
- OpenCascade/pythonOCC for STEP parsing
- Three.js for 3D viewing
