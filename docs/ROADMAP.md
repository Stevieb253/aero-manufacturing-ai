# Aerospace Manufacturing AI Roadmap

---

# Phase 1 - Foundation MVP

Goal:
Create a system that can upload and analyze STEP/STP files.

Features:
- Upload STEP/STP files
- Store uploaded files
- Dashboard for uploaded parts
- Extract:
  - bounding box dimensions
  - volume
  - surface area
- Generate part report page

Status:
- In Progress

---

# Phase 2 - 3D Viewing

- Basic measurements
- Screenshot export
