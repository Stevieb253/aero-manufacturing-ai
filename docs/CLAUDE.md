# Claude Project Instructions

## Project Overview
This project is an aerospace manufacturing assistant focused on analyzing STEP/STP files and assisting manufacturing workflows.

## Current Goal
Build the first MVP:
- Upload STEP/STP files
- Store uploaded files
- Extract geometry metadata
- Display uploaded parts
- Generate part reports

## Architecture Requirements
- Modular architecture
- Clean scalable code
- Production-oriented structure
- Separate backend/frontend
- API-first design

## Backend Stack
- Python
- FastAPI
- PostgreSQL

## Frontend Stack
- React
- Three.js

## CAD/Geometry
- OpenCascade
- pythonOCC

## Important Rules
- Do NOT over-engineer early phases
- Do NOT add AI machining logic yet
- Do NOT generate CNC code
- Keep the MVP focused and small
- Prioritize maintainability
- Use clear folder structures
- Add comments where helpful

## Initial MVP Focus
The MVP only needs:
1. STEP/STP upload
2. File storage
3. Basic geometry extraction
4. Dashboard display
5. Part report pages

## Future Focus
Future phases may include:
- Feature recognition
- Manufacturability analysis
- Cost estimation
- Machine recommendations
- AI manufacturing assistant

Make no mistakes.
